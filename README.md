# L3: depozitul meu personal

Sarcina individuală L3 de la disciplina *Dezvoltare colaborativă și tehnologii cloud* (DCTC), UTCN CUNBM. Termenul este cel din activitatea *L3: depozitul personal* de pe Campus Virtual. Verificarea este automată la fiecare `push` (fila *Actions*): rezumatul rulării arată punctele pe fiecare criteriu; poți corecta până la termen.

## Ce ai de făcut

1. Depozitul acesta este al tău, creat din șablonul cursului, **privat**. Adaugă titularul drept colaborator: *Settings > Collaborators > Add people*, utilizatorul `cosminsabo`. Fără acces, depozitul nu poate fi notat.
2. Clonează depozitul în VS Code (*Source Control > Clone Repository*, sau comanda *Git: Clone*).
3. Completează secțiunile de mai jos (înlocuiește textul dintre `<...>`), în cel puțin **trei commit-uri** separate, cu mesaje clare (imperativ, în engleză, sub 50 de caractere; de exemplu `Add about-me section`).
4. Creează fișierul `despre-mine.md` (cel puțin 50 de cuvinte: cine ești, ce te-a adus la această specializare, ce ai vrea să știi să faci peste un an).
5. `push` și verifică bifa verde din *Actions*. Dacă e roșie, deschide rularea și citește în rezumat ce lipsește.
6. Predă pe Campus Virtual, în activitatea *L3: depozitul personal*, link-ul acestui depozit.

Nu adăuga fișiere mari, parole sau chei; `.gitignore` rămâne în depozit. Nu modifica folderele `tests/` și `.github/`.
