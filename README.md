# L3: depozitul meu personal

Sarcina individuală L3 de la disciplina *Dezvoltare colaborativă și tehnologii cloud* (DCTC), UTCN CUNBM. Termenul este cel din activitatea *L3: depozitul personal* de pe Campus Virtual. Verificarea este automată la fiecare `push` (fila *Actions*): rezumatul rulării arată punctele pe fiecare criteriu; puteți corecta până la termen.

## Ce aveți de făcut

1. Depozitul acesta este al dumneavoastră, creat din șablonul cursului, **privat**. Adăugați titularul drept colaborator: *Settings > Collaborators > Add people*, utilizatorul `cosminsabo`. Fără acces, depozitul nu poate fi notat.
2. Clonați depozitul în VS Code (*Source Control > Clone Repository*, sau comanda *Git: Clone*).
3. Completați secțiunile de mai jos (înlocuiți textul dintre `<...>`), în cel puțin **trei commit-uri** separate, cu mesaje clare (imperativ, în engleză, sub 50 de caractere; de exemplu `Add about-me section`).
4. Creați fișierul `despre-mine.md` (cel puțin 50 de cuvinte: cine sunteți, ce v-a adus la această specializare, ce ați vrea să știți să faceți peste un an).
5. `push` și verificați bifa verde din *Actions*. Dacă e roșie, deschideți rularea și citiți în rezumat ce lipsește.
6. Predați pe Campus Virtual, în activitatea *L3: depozitul personal*, link-ul acestui depozit.

Nu adăugați fișiere mari, parole sau chei; `.gitignore` rămâne în depozit. Nu modificați folderele `tests/` și `.github/`.
